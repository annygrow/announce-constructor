# Пайплайн: пачка HTML-писем по дизайн-шаблону

Отработано на цепочке «Акселератор» (18 писем) 16.06.2026. Рабочие копии скриптов — в `Desktop/Claude/gc_automation/` (`parse_letters.js`, `build_mailings.js`, `gen_runfile.js`).

## 3 шага

**1. `parse_letters.js`** — Markdown (экспорт из Google Docs) → `letters_parsed.json` `[{header, subject, fromName, ctas[], body[]}]`.
Ключевое:
- выкинуть дефиниции картинок `^\[image\d+\]:` и инлайн `!\[\]\[image\d+\]`;
- снять экранирование: `s.replace(/\\(.)/g,'$1')` (даёт `{first_name}`, `!`, `[`);
- сегментировать по заголовкам `/(Письмо|ПИСЬМО)\s*([\d.]+)/`;
- `Тема:` → subject (убрать `*`), `от кого:` → fromName;
- строки-таблицы `| ... |` → текст (строки-сепараторы `:----` дропнуть);
- одиночные `[Текст]` → ctas; **эмфазу `**`/`*` в body сохранить**.

**2. `build_mailings.js`** — `letters_parsed.json` → `letters_built.json` `[{name, subject, html}]` + `sample_email.html` для глаз.
- оверрайды (хвост темы в 2 строки → вернуть в subject; где темы нет → задать);
- `PICK` — индексы писем с контентом (пустые заглушки пропустить);
- `render(letter)`: лого → плейсхолдер баннера → серая карточка с телом → синие CTA-карточки с жёлтой кнопкой → тёмный футер. Всё **inline-стилями** (токены вытащены из дизайн-шаблона);
- конвертер: `***x***→<strong><em>`, `**x**→<strong>`, `*x*→<em>`; инлайн `[x]`→кнопка; нумерованные/`✔️✅📌📍`-строки — плотнее; `{first_name}` не трогать.

**3. `gen_runfile.js START COUNT`** — встраивает `letters_built.json` в готовую функцию `run_create_mailings.js` (`async (page)=>{...}`) с логин-гардом и циклом `createHtmlMailings`. Запуск: `browser_run_code_unsafe({filename:'.../run_create_mailings.js'})`.

## Грабли запуска
- В sandbox `browser_run_code_unsafe` НЕТ `require`/`fs` — только `page`. Данные писем **эмитить в сам файл** (через генератор), не читать с диска в рантайме.
- Тул-вывод раздувается эхом всего кода файла (≫ лимит токенов, уходит в сохранённый tool-result). Возвращать компактный `results`; парсить его из сохранённого файла (`grep -oE '\{"name":"…"(ok|error)…\}'`).
- Тестировать на 1 письме (`gen_runfile.js 0 1`), свериться `verifyMailingHtml` (число `<table`), затем гнать остальные (`gen_runfile.js 1 999`).
- Предпросмотр HTML до GC: `file://` заблокирован — рендерить через `data:text/html;base64,<...>` (navigate) и скриншот.
