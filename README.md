# Конструктор рассылок

Веб-приложение для автоматической генерации рассылок из Google Документа во все нужные каналы.

---

## Проблема

У каждого канала рассылки — свой текст. Email для GetCourse, email для Unisender, Telegram-каналы и боты — в документе для каждого написан разный вариант. Специалист вынужден открывать документ снова и снова, находить нужную секцию, копировать текст и верстать его под требования конкретного канала. Это 4–10+ ручных операций на один анонс, и при этом легко ошибиться или перепутать версии. Плюс согласование вёрстки — на это уходит время всей команды.

---

## Для кого

Технический специалист, который отвечает за рассылки в онлайн-школе или маркетинговой команде: вёрстает письма и Telegram-сообщения в несколько разных каналов одновременно.

---

## Как это работает

1. Копируешь ссылку на Google Документ с текстом анонса
2. Вставляешь в приложение и нажимаешь «Сгенерировать»
3. Приложение парсит документ и автоматически формирует вёрстку для каждого канала
4. Получаешь готовый результат по всем каналам — с уже размеченными UTM-ссылками, можно сразу копировать и вставлять

Документ разбивается на секции (Почта, ТГ, тема письма, прехедер) — приложение понимает структуру и правильно раскладывает контент по каналам.

---

## Что получит пользователь

- **Email для GetCourse** — готовый HTML в фирменном стиле компании: блочная вёрстка с белыми, серыми и синими блоками, CTA-кнопки, картинки, 2–3 колонки. Переменные платформы (`{first_name}`, `{offer_url_...}`) подставляются автоматически и сохраняются корректно
- **Email для Unisender** — автоматически берётся нужная версия текста из документа, GC-переменные убираются, вёрстка адаптируется под платформу
- **Telegram-каналы и боты** — форматированный текст для каждого канала отдельно, с учётом особенностей каждого: где нужен HTML, где обычный текст
- **Нейрокот (Markdown)** — текст в формате Markdown с отдельным блоком UTM-ссылок для вставки вручную
- **UTM-ссылки** — размечаются автоматически для всех каналов с правильными параметрами

Результат по каждому каналу — это готовый код или текст, который можно сразу скопировать и вставить. Не нужно ничего доделывать вручную.

Все результаты открываются во вкладках. Прямо в интерфейсе можно редактировать каждый блок, переставлять их местами и видеть превью письма — без перезапуска.

---

## Основные возможности

**Умный парсинг документа**
Приложение читает структуру Google Документа и само разбирается, где email, где Telegram, где тема письма и где прехедер. Никаких шаблонов и инструкций — просто пишешь документ в привычном формате.

**Автоматическая вёрстка блоков**
Тип блока определяется по содержимому: эмодзи в начале абзаца, чекмарки, квадратные скобки вокруг текста кнопки — приложение всё это видит и оформляет нужным образом. Два одинаковых блока подряд автоматически чередуются по цвету — письмо выглядит живо.

**Полноценный редактор прямо в браузере**
Каждый блок можно отредактировать: изменить текст, поменять ссылку на кнопке, добавить форматирование через тулбар (жирный / курсив / подчёркнутый / ссылка). Перетащить блок на другое место — drag-and-drop. Рядом — превью готового письма, обновляется сразу.

**Разные версии текста для разных каналов**
В документе — разные версии для разных каналов. Приложение знает, какую версию взять для каждого: для email GetCourse, для Unisender, для конкретного Telegram-канала. Не нужно самому следить, что куда идёт.

**Правильные переменные и ссылки везде**
`{first_name}` сохраняется там, где нужен (GetCourse), убирается там, где не нужен (Unisender, Markdown), и заменяется на нужный формат там, где формат другой (боты). UTM-метки размечаются автоматически — с правильными параметрами для каждого канала.

## Технологии

| Что | Чем |
|---|---|
| Backend | Python 3, Flask |
| Парсинг документов | BeautifulSoup4, lxml |
| Источник контента | Google Docs (экспорт в HTML) |
| Frontend | Vanilla JavaScript, CSS (тёмная тема) |
| Запуск | Локально, без деплоя |

---

## Запуск

```bash
# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python app.py
```

Открыть в браузере: `http://127.0.0.1:5000`
