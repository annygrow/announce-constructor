# Конструктор рассылок

Веб-приложение для автоматической генерации рассылок из Google Документа во все нужные каналы.

---

## Проблема

Технический специалист, который верстает анонсы, вынужден делать одно и то же несколько раз: взять один и тот же текст и оформить его отдельно для email в GetCourse, отдельно для email в Unisender, отдельно для каждого Telegram-канала и бота. Это 4–10+ ручных операций на один анонс. Плюс согласование вёрстки — на это уходит время всей команды.

---

## Для кого

Технический специалист, который отвечает за рассылки в онлайн-школе или маркетинговой команде: вёрстает письма и Telegram-сообщения в несколько разных каналов одновременно.

---

## Как это работает

1. Копируешь ссылку на Google Документ с текстом анонса
2. Вставляешь в приложение и нажимаешь «Сгенерировать»
3. Приложение парсит документ и автоматически формирует вёрстку для каждого канала
4. Получаешь готовый результат по всем каналам — можно сразу копировать и вставлять

Документ разбивается на секции (Почта, ТГ, тема письма, прехедер) — приложение понимает структуру и правильно раскладывает контент по каналам.

---

## Что получит пользователь

- **Email для GetCourse** — готовый HTML с блочной вёрсткой: белые, серые, синие блоки, CTA-кнопки, картинки, 2–3 колонки. Поддерживает переменные GC (`{first_name}`, `{offer_url_...}`)
- **Email для Unisender** — тот же текст, другой формат; GC-переменные автоматически убираются
- **Telegram-каналы и боты** — форматированный HTML-текст для каждого канала отдельно, с учётом особенностей каждого (жирный, курсив, ссылки)
- **Нейрокот (Markdown)** — текст в формате Markdown с отдельным блоком UTM-ссылок для ручной вставки
- **UTM-ссылки** — автоматически генерируются для всех каналов с нужными параметрами

Все результаты открываются во вкладках. Можно редактировать каждый блок прямо в интерфейсе — менять текст, переставлять блоки местами, добавлять новые — и сразу видеть превью письма.

---

## Основные возможности

- Автоматическое определение типа блока по содержимому (эмодзи, чекмарки, `[КНОПКА]`)
- Редактор блоков с тулбаром форматирования (жирный / курсив / подчёркнутый / ссылка)
- Drag-and-drop: перетаскивание блоков в нужном порядке
- Чередование блоков: два одинаковых блока подряд автоматически чередуются (белый → серый)
- Превью письма прямо в браузере
- Разные варианты TG-текста: если в документе несколько TG-секций, можно переключаться между ними
- Умная обработка имени: `{first_name}` сохраняется там, где нужно, и убирается там, где не нужно

## Технологии

| Что | Чем |
|---|---|
| Backend | Python 3, Flask |
| Парсинг документов | BeautifulSoup4, lxml |
| Источник контента | Google Docs (экспорт в HTML) |
| Frontend | Vanilla JavaScript, CSS (тёмная тема) |
| Запуск | Локально, без деплоя |

---

## Запуск

```bash
# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python app.py
```

Открыть в браузере: `http://127.0.0.1:5000`
